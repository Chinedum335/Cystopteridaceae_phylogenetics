## Cystopteridaceae_phylogenetics

This repository contains data, scripts, configuration files, and analytical workflows used for PURC processing and homologizer phylogenetic analyses in the article: Cystopteridaceae in focus: A model clade for studying polyploid systematics and macroevolution.

The repository is organized to facilitate reproducibility of sequence processing, homeolog phasing, MUL-tree inference, and downstream visualization.

### Repository Structure

-  `01_purc`

    -  This directory contains files required to run PURC for long-read amplicon sequence processing.
         -  PURC_config_file.txt - Configuration file used to run PURC.
         -  Barcode_seq.fasta - Pacific Biosciences barcode sequences used for demultiplexing.
         -  Reference_seq.fa - Reference sequences for Cystopteridaceae used during PURC processing.

-  `02_homologizer_data_and_scripts`

    -  This directory contains all data and scripts used to prepare and run homologizer analyses, including mul-tree backbone construction and phasing workflows. The structure of the directory is as follows
    
    -  `/01_Scripts_for_homologizer_setup_and_plotting`
        -  This directory contains all the scripts for generating homologizer inputs, running homologizer and plotting phasing results.

        - `01_generate_homologizer_inputs_and_phase_setup.R` - This script can be used to generate all required inputs to run 02_homologizer_main_script.rev script. This script takes as input Generate_phase.csv. Output generated by this script include:
            - `InitialPhase.rev` - This is the file that contains the initial phase assignment before running homologizer
            - `PhaseMoves.rev` - This file sets up all the phasing MCMC moves for all the tips
            - `paired_tip_constraint.rev` - This file sets up the paired- tip clade used to constrain sister tips
            - `subgenomes_names.csv` - Important script used to subgenome tip labels for plotting.
          
          This script is generalizable and can be used for any polyploid dataset requiring homologizer phasing with paired-tip constraints.

        -  `Generate_phase.csv` - This is the input file for 01_generate_homologizer_inputs_and_phase_setup.R. This file specifies, for each locus, the number of sequence copies recovered and the number of tips that should be paired in the phylogeny. 
            - Column descriptions
                - Sample - the base name for each tip
                - sample_ID - the accession number of the sample to be phased
                - No_subgenome - Total number of tips expected to be paired. For example, a value of 4 indicates that two pairs of tips are expected in the phylogeny. APP-TRNGR - Number of copies recovered for each locus for that accession.
        
        For this setup to work, individual homeologous sequences in the input sequence file must follow the naming convention sample_ID_c1, sample_ID_c2, etc. (e.g., 16972_c1, 16972_c2). See the sequence data files in the provided phasing examples for reference.

        -  `02_homologizer_main_script.Rev` - This is the main RevBayes script used to run homologizer. This script takes as input your sequence data for each locus, InitialPhase.rev, PhaseMoves.rev, paired_tip_constraint.rev and generates an output folder that contains the phasing results and the map.tree

        -  `03_plot_phase_script.R` - This is the script used to plot the result of homologizer. The directory of the output folder has to be specified. Also this script takes subgenomes_names.csv as input and the output is the plot of the phasing.

    -  `/03_phasing_examples`
       -  This directory contains worked examples illustrating homologizer phasing for selected Cystopteridaceae taxa.

        -  `/01_phasing_C_tenuis`
            -  `/data` - contains the input sequence data for each locus used in the phasing of C_tenuis. content include APP_homologizer.fa, GAP_homologizer.fa, IBR_homologizer.fa, PGI_homologizer.fa, TRNGR_homologizer.fa
            -  `/homologizer_scripts` - contains all the relevant homologizer scripts for implementing paired-tip constraint and also plotting the phase. It includes 02_homologizer_main_script.Rev, InitialPhase.rev, PhaseMoves.rev, paired_tip_constraint.rev, subgenomes_names.csv and 03_plot_phase_script.R scripts. 
            -  `C_tenuis_Plot.pdf` - final plot of the run. 

        -  `/02_phasing_G_xintermedium`
            -  `/data` - contains the input sequence data for each locus used in the phasing of G_xintermedium. 
            -  `/homologizer_scripts` - contains all the relevant homologizer scripts for implementing paired-tip constraint and also plotting the phase.
            -  `G_xint_Plot.pdf` - final plot of the run. 
        -  `/03_phasing_C_laurentiana`
            -  `/data` - contains the input sequence data for each locus used in the phasing of C_laurentiana
            -  `/homologizer_scripts` - contains all the relevant homologizer scripts for implementing paired-tip constraint and also plotting the phase.
            -  `C_lau_Plot.pdf` - final plot of the run.
